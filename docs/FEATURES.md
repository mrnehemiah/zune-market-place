# ZUNE Marketplace feature map

## Included in this build
- Premium responsive home page and product feed
- Search and category navigation
- Product detail pages
- Buyer registration, login, password reset and profile edit
- Guest and signed-in cart/wishlist
- Checkout order request (payments disabled)
- Buyer order history
- Seller application workflow
- Seller Center gated by approved `vendor` role
- Seller product creation and deletion
- Buyer-to-seller conversation start and messaging data service
- Notifications page
- ZUNE AI local guided assistant
- Verification status display (gold buyer badge, blue verified-store badge)
- Official WhatsApp Channel join and private contact button
- Animated mobile bottom navigation and responsive desktop layout
- PWA manifest and service worker

## Separate system
ZUNE PREMIUM ADMIN remains separate. This Marketplace contains no Admin dashboard, admin sidebar or admin route.

## Deferred
- Mobile money and all payment collection/verification
- Provider API/webhook reconciliation
- Live generative AI provider credentials
- Product image upload to Storage (image URL is supported in seller product form)
- Push notification provider
- Full review/rating and dispute workflows
